守住你的账号、钱包与隐私

大学四年里，你会注册几十个账号、连上无数个 WiFi、收到成百上千封邮件。 攻击者不需要多高深的技术——他们只需要你的一次疏忽。 本文用最短的篇幅讲清三件事：怎么设密码、怎么识破钓鱼、怎么保护个人信息。

Part 01 · Password

密码安全：一次泄露，全线崩塌

大多数“被盗号”并不是被暴力破解的，而是因为你在某个不重要的论坛用过同一个密码。 那个论坛被拖库之后，攻击者拿着这组账号密码去撞你的邮箱、微信、支付宝—— 这在黑产里叫 撞库，成功率比你想象的高得多。

✕

这些做法的风险

  • 一码多用：任意一处泄露，全部账号失守
  • 弱口令：123456、abc123、生日、手机号
  • 规律变形：Password1 → Password2
  • 明文存放：存进微信收藏、备忘录、聊天记录
✓

推荐的做法

  • 密码短语：4～5 个不相关的词 + 数字符号，如 火锅-鲸鱼-7-月亮
  • 一账号一密码：每个重要账号都是独立的一组
  • 密码管理器：只记住一个主密码，其余交给工具生成
  • 长度优先：12 位以上，长度比复杂度更重要
🔒

比密码更重要：两步验证

开启两步验证（2FA）后，即使密码被偷，对方没有第二个因素也进不去。 优先选择 验证器 App（如 Microsoft Authenticator）或 硬件安全密钥； 短信验证码虽然比没有强，但存在被 SIM 卡劫持的风险。

推荐：验证器 App 可用：短信验证码 避免：只在单一设备上

把学校和企业账号当“高价值目标”

校园统一身份认证、教务系统、邮箱、云盘往往互相打通。 攻破其中一个，等于拿到了你成绩、课表、个人信息甚至其他系统权限的钥匙。 这类账号请务必修：独立强密码 + 两步验证 + 不与其他网站共用。

关于“安全问题的答案”：把“母亲的名字”“出生城市”当作找回密码的问题，等于把密码写在了朋友圈上。 在社交平台公开的信息，一律不要用于密保问题。

密码自测：现在就试试

下面的检测在你的浏览器本地完成，输入内容不会被上传或保存。 试着输入你正在用的密码，看看它能打几分。

    Part 02 · Phishing

    识别钓鱼消息：先怀疑，再点击

    钓鱼攻击利用的是情绪：紧急、恐惧、好奇、贪便宜。 标题越吓人、优惠越夸张、时间越紧迫，你越要慢下来。 记住一个原则：正规机构不会通过短信或邮件索要你的密码和验证码。

    ⏱

    制造紧迫感

    “24 小时内不处理将冻结账号”“最后 2 小时领取”。

    ✉

    仿冒发件人

    显示名是“教务老师”，真实地址却是随机免费邮箱。

    🔗

    域名近似

    tsinghua-edu.cn、sch00l.com 这类只差一两个字符的域名。

    🎣

    索要敏感信息

    要密码、要验证码、要身份证照片、要银行卡号。

    一眼看穿几种常见骗局

    骗局类型典型话术 / 场景破绽点（红旗信号）
    奖学金 / 助学金诈骗 “你已获评国家级奖学金，请点击链接填写银行卡与验证码领取” 要验证码、要银行卡密码；发放流程不会通过短信链接完成
    教务 / 学籍通知 “你的学籍状态异常，请登录 xxx-edu.com 核验” 域名与学校官网不一致；用真实官网域名逐一比对
    兼职 / 刷单返利 “日结 300，先垫付再返现” 要先交钱、先垫资的兼职基本都是骗局
    快递 / 退票类短信 “您的包裹丢失，点击链接填写信息进行理赔” 去官方 App 或官网核对订单，从不点短信里的链接
    冒充熟人借款 “我是你辅导员／室友，急用钱，先用微信转我” 换一个渠道当面或电话核实身份
    WiFi / 二维码 扫码连陌生 WiFi、扫码“激活校园卡” 公共 WiFi 可能被克隆；不明二维码不扫

    收到可疑消息时的“五步法”

    1. 停：不点链接、不下载附件、不回复
    2. 看：把鼠标悬停在链接上，看真实域名（手机可长按预览）
    3. 查：用官方 App / 官网 / 官方电话独立核实，不通过消息里的联系方式
    4. 问：向同学、辅导员、学校信息化部门求证
    5. 报：确认是钓鱼就举报，并提醒身边同学

    链接怎么看真假

    域名的主体部分（紧挨着 .com/.cn 前面的那一段）才是真正的归属：

    www.school.edu.cn可信
    school.edu.cn.evil.com钓鱼
    sch00l.edu.cn钓鱼（数字 0 冒充字母 o）
    短链接（bit.ly、t.cn 等）会掩盖真实地址，收到时先展开或直接忽略。
    Part 03 · Privacy

    个人信息保护：减少被“拼图”的可能

    单独看，姓名、学号、宿舍楼、常去的奶茶店都不算秘密； 但把它们拼在一起，攻击者就能冒充你去骗你的家人，或者精准地给你发一条“无法识破”的钓鱼短信。 隐私保护的核心，就是别让别人轻易完成这块拼图。

    🪪

    核心敏感信息

    这些信息一旦泄露，危害直接且难以挽回：

    • 身份证号与正反面照片
    • 银行卡号、支付密码、短信验证码
    • 人脸、指纹等生物特征
    • 学信网 / 教务系统账号
    📱

    社交平台别晒这些

    • 车票、机票、登机牌（二维码含身份信息）
    • 学生证、校园卡、宿舍门牌
    • 实时定位、考勤打卡截图
    • 快递面单（记得撕掉或涂掉姓名电话）
    晒照前问一句：这张图能让我被找到吗？
    ⚙

    App 与设备设置

    • 安装时只授予必要权限（手电筒不需要通讯录）
    • 关闭“允许陌生人查看十条朋友圈”
    • 导出或关闭个性化广告追踪
    • 旧手机、旧电脑转卖前彻底抹除数据

    公共 WiFi 与公共电脑的正确姿势

    • 不登录网银、支付、校园账号等敏感系统
    • 优先使用手机热点；必须用时，只访问 HTTPS 网站
    • 关闭设备的“自动连接已知 WiFi”，避免连上同名钓鱼热点
    • 网吧、打印店电脑用完要退出账号并清除浏览记录

    实名认证与个人信息

    注册小网站时要身份证、要人脸时，先问自己：这个服务值得交出这些吗？ 各类“测试类”小程序（测性格、测颜值、测运势）常常以娱乐为名收集姓名、手机号与照片， 尽量避免使用真实信息。

    《个人信息保护法》赋予你知情、删除与撤回同意的权利。遇到明显过度收集，可以向平台投诉或向网信部门举报。

      Part 06 · Response

      万一已经中招：黄金 72 小时

      发现自己点了钓鱼链接、泄露了验证码，或在陌生设备登录过，按顺序做下面几件事。

      1. 立刻改密码

        在安全设备（自己的手机或可信电脑）上修改邮箱、校园账号、支付类 App 的密码，并开启两步验证。

      2. 踢掉陌生登录

        在账号安全设置里查看“登录设备管理”，注销所有不认识的设备与会话。

      3. 冻结资金相关

        联系银行或支付平台冻结卡片、修改支付密码，检查是否有异常交易与免密支付授权。

      1. 通知可能被冒充的对象

        告诉家人、同学、辅导员：你的账号可能被盗，收到借钱、转账请求务必先电话核实。

      2. 保留证据并报警举报

        截图保存聊天、短信、转账记录，向学校信息化部门报告；涉及转账可拨打 96110 反诈专线或报警。

      3. 复盘并加固

        检查是否还有其他平台用了同一密码，全部改掉；订阅账号泄露查询服务，及时获知风险。

      记住一句话：任何时候，验证码、密码、身份证照片 都不应该出现在聊天框、短信回复或者来路不明的网页表单里。
